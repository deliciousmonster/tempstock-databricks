# Claims and sources

Sources are tracked paths in this repository at the merge of the presentation lane (`a73743a`) on `main` unless marked otherwise; later changes to a cited file are noted on its row. "Measured" means a run recorded in the named evidence; "read" means taken from the source or a document and not run for this write-up. `WMT` is the ticker the signal calls.
